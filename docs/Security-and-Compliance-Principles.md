# Security and Compliance Principles

Security, privacy and compliance are product features.

## Core requirements
- privacy by design
- tenant isolation
- encryption in transit and appropriate at-rest protection
- MFA support
- secure sessions
- session/device visibility and revocation
- re-authentication for sensitive actions
- role-based permissions
- server-side authorization
- audit logging
- secure secret management
- least-privilege production access
- tested backups and recovery
- incident response process

## GDPR
Support:
- DPAs
- subprocessor transparency
- data subject rights
- deletion/retention workflows
- export
- privacy documentation
- DPIA-supporting information where applicable

## Data location
Prefer EU/EEA hosting and subprocessors where practical for European customers, and document data location clearly.

## Retention
Allow category-specific retention where appropriate while respecting legal retention obligations.

## Compliance evidence
Maintain evidence for technical/organizational measures, security reviews, subprocessors, retention, incidents and restore tests.

## Customer trust
Provide understandable documentation for security, privacy, data handling, data location, subprocessors and contractual responsibilities.
