# WorkCore Product Foundation v2

This documentation set consolidates the founder workshop into a durable product foundation for WorkCore / Koll.

## Product identity
**WorkCore** is the international/default brand.
- German claim: **Aufträge. Projekte. Service. Abrechnung.**
- English claim: **Jobs. Projects. Service. Billing.**

**Koll** is the Swedish-market brand.
- Swedish claim: **Full koll på jobbet.**

Core character: **Easy. Professional. Clear.**

Core principle:
> The software adapts to the business — not the other way around.

AI principle:
> WorkCore thinks along — but does not decide for the user.

## Priority interpretation
A rating of 3 means strategically essential. It does not mean every capability belongs in V1. Roadmap sequencing remains a separate step.

## Authority
When implementation choices conflict:
1. Non-Negotiables
2. Architecture/security constraints
3. Product requirements
4. UX/design principles
5. Module-specific details
