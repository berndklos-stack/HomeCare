# WorkCore / Koll – Non-Negotiables

These principles are mandatory across product, design and engineering.

## Product
- WorkCore must be easy to use.
- WorkCore must be professional.
- WorkCore must be clear.
- A non-technical user must be able to understand the product intuitively.
- A new user should not require formal training.
- The software adapts to the business, not the other way around.
- The product must remain modular.
- The product must grow with the company.

## UX
- The interface must never be confusing.
- Important actions must be immediately recognizable.
- Common workflows must require as few interactions as reasonably possible.
- Important mobile controls must be touch-friendly and one-hand usable.
- Mobile must be intentionally designed.
- Main areas must be reachable quickly.
- Search must be fast and easy to reach.
- Global search must exist across major entities.
- Filtering and sorting must be simple.
- Long forms must be structured.
- Advanced options must stay out of the way until needed.
- Status must be immediately understandable.
- Important actions must always provide feedback.
- Critical mistakes should be recoverable.
- Important deleted data should be recoverable.
- Help should be contextual.
- Empty states must guide the user.
- Long-running operations must show progress.
- Long inputs must support drafts/autosave.

## Reliability
- Data integrity is never negotiable.
- WorkCore must never silently lose data.
- WorkCore must not silently overwrite conflicting data.
- The user must be able to trust the state shown on screen.
- Important changes must be auditable.
- Important data should support version restore.
- Backups must be automatic.
- Sync status must be visible.
- Device switching must be reliable.
- Offline work must be safe.
- Server state is authoritative.
- Local state is cache/offline support, not a competing source of truth.

## Performance
- The product must feel fast.
- Buttons and primary actions must respond immediately.
- Loading must not unnecessarily block the interface.
- Performance is a product feature.

## Multi-Device
- iPhone, Android, Mac, Windows and tablet experiences must stay conceptually consistent.
- Users must be able to continue work on another device.
- Active workflows must be centrally synchronized.
- Safe changes should merge automatically.
- True conflicts must be surfaced clearly.

## Security and Privacy
- Privacy by Design is mandatory.
- Sensitive data must be protected appropriately.
- Roles and permissions must remain understandable.
- Data must be exportable.
- Users must not be locked into the platform.
- Vendor dependence should be minimized.

## AI
- AI must not take critical irreversible actions without explicit approval.
- Important AI output must be reviewable.
- Important recommendations must be explainable.
- AI must not be required to use the product.
- AI must support, not control.
- Automations must be visible and controllable.
- New automations must not silently activate.

## Customization
- Companies must be able to define sensible defaults.
- Users may have personal defaults where appropriate.
- Configuration must remain easy.
- WorkCore must start with strong defaults and should not require extensive setup.

## Final Rule
> Trust, clarity and data integrity always take priority over adding another feature.
