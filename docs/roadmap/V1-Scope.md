# WorkCore V1 Scope

## Launch rule
> **Stability before scope.**

V1 is broad, but WorkCore is only launch-ready when the core product is secure, tenant-safe, synchronization-safe, operationally reliable and validated.

- OCR and document/photo extraction
- voice-to-structured-data
- document classification
- contract/date/deadline extraction
- proactive risk hints
- next-step suggestions

- summaries

## V1 platform requirements
- authoritative authentication
- tenant/company context
- server-side authorization
- tenant isolation / RLS
- secure portal auth
- durable offline queue
- idempotent mutations
- revision-aware updates
- conflict detection
- recoverable deletion
- safe media deletion
- backup/restore over the real source of truth
- complete data export
- status page
- go-live checklist

## Initial market readiness
- Sweden
- Germany
- DE/SV/EN UI and document/communication support

A feature is not V1-ready just because the UI exists. It must also be secure, tenant-safe, reliably persisted, appropriately synchronized, tested and recoverable.
