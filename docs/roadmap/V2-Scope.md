# WorkCore V2 Scope

## Early expansion
- Employee self-service portal
- Role-specific dashboards
- Personalized start pages
- Advanced notification rules
- Mobile push notifications
- Structured team / shift handover
- Complaints / defects / rework
- Advanced approval workflows
- Standard approval templates
- Expenses / outlays
- Post-calculation / planned-vs-actual profitability
- SSO (e.g. Microsoft Entra ID / Google Workspace)
- Structured e-invoices (Peppol / XRechnung / ZUGFeRD)
- Central audit-log UI
- Advanced data-retention rules
- In-app support
- In-app changelog
- Advanced admin/system-health dashboard
- Formalized release gates
- Advanced monitoring / alerts
- Workflow simulation / dry-run
- Advanced anomaly detection
- Forecasting

V2 must build on the V1 architecture and must not reintroduce parallel sources of truth or client-only security.
