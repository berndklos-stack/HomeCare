# Design Manifest

## Core statement
**Easy. Professional. Clear.**

WorkCore should feel obvious without feeling simplistic.

### Principles
- Common work stays close.
- Complexity is progressive.
- Large, touch-friendly controls.
- Icons support meaning; labels explain.
- Context beats deep navigation.
- Calm status communication.
- Never hide data uncertainty.
- Good empty states explain what belongs there and what to do next.
- Strong, safe defaults.
- Role-aware start pages.
- Mobile continuity after interruption.
- One-handed mobile operation for frequent field tasks.
- Few interruptions; confirm mainly irreversible, financial or externally visible actions.
- Central design system.
- Accessibility and clarity from the beginning.
- Dark mode desirable, never at the cost of readability.
- Customization must not fragment the product.
