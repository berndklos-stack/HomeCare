# User Experience Principles

## Desktop
- Clear hierarchy
- Contextual actions
- Minimal navigation depth
- Useful tables, filters and saved views
- Fast movement between customer, project, job, communication, documents and billing

## Mobile / field
Mobile must support real work:
- today/current jobs
- time tracking
- trip start/end
- notes
- photos
- checklists
- signatures
- service reports
- customer communication
- task completion
- approvals

Principles:
- one-hand friendly
- large touch targets
- minimal typing
- smart defaults
- voice where useful
- camera as a first-class input
- quick capture and quick actions
- graceful operation on slow/unstable networks
- resume reliably after app close, sleep or network changes

## Offline and sync
- work locally where safe
- queue changes durably
- show a calm offline state
- avoid repeated popups
- sync later automatically
- surface failures/conflicts clearly

## Notifications
Only relevant events should notify. Notifications should deep-link to the action.

## Team UX
Support ownership, handover, comments, mentions, shared files, activity history, approvals, delegation, escalation and team views.

## Communication
Clearly distinguish internal notes from customer-visible or partner-visible messages.
